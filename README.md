# Synapsis Clínico — Landing Page Oficial

Repositório oficial da Landing Page Institucional do **Synapsis Clínico** ([synapsisclinico.com.br](https://synapsisclinico.com.br)).

## 🚀 Arquitetura & Infraestrutura
- **Hospedagem:** AWS Amplify Hosting (CI/CD contínuo conectado a este repositório)
- **CDN Global:** Amazon CloudFront Edge Network
- **DNS:** Amazon Route 53
- **E-mails Corporativos:** Zoho Mail integrado (`contato@synapsisclinico.com.br` / `suporte@synapsisclinico.com.br`)
- **Captura de Leads:** Integração direta com despacho automático via FormSubmit + redundância em `localStorage`

## 📁 Estrutura de Arquivos
- `index.html`: Página principal com apresentação dos módulos, comparativo técnico, calculadora e formulário do Clube das Fundadoras.
- `contrato-blindado-avaliacao-psicoterapia.html`: Modelo de contrato jurídico para psicólogos com cláusulas anti-inadimplência e conformidade CFP/LGPD.
- `robots.txt` & `sitemap.xml`: Otimização para indexação orgânica em buscadores.
- `synapsi_brain1.png` & assets visuais: Identidade visual oficial.
